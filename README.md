# birchwood_web1
Website for BirchwoodHolidayCottage V1

# about
This was a website that I was tasked to make by the owners of a small holiday let in the highlands of Scotland.
The old website was very clunky, espescially when veiwed on a mobile phone, so that was something I needed to implement.
A added the following pages:
- Activities: All the things that you can do in the area where the house is
- Details: An overveiw of what the house is like
- Enquires: How to contact the owners about hiring the home
- Index (home)
- Location: A map and description on how to get to the house
- Pricing: The owners can edit the avaliability and pricing
- Reviews: Some reviews of the house
- Terms: Terms and conditions (yawn!)
